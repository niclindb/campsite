# Gallery photos

Every image in this folder (.jpg, .jpeg, .png, .webp or .avif) shows up in
the home page gallery automatically, in file-name order. Start names with
a number (01-, 02-, ...) to control the order.

To give a photo a caption, add a line for it to `galleryCaptions` in
`src/content/site.ts`. The caption is written under the photo and read by
screen readers.

Keep photos around 1600 px on the long side so the page stays fast.
